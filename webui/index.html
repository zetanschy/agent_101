Policy · any mode
Flow-matching steps per inference. 10 = pi05 default; lower is faster, less accurate.
Actions executed per inference. 50 (default) = 1.7 s open-loop at 30 fps; 10–15 re-plans far more often. Biggest lever in sync.
sync · active
sync exposes no engine params of its own — the arm holds still while the policy thinks, then plays the whole chunk. Shorten action steps above to cut the open-loop window, or switch to rtc to keep it moving.
rtc · active
Actions run per chunk before recomputing, and the queue depth that triggers the next inference.
openpi · active
rtc is async plus real-time chunking: the next chunk is generated knowing which actions will already have run when it lands, so the seam is continuous instead of a jump. async predicts ahead but splices in cold. sync holds still while it thinks (what the April setup did). All three use action steps above as the window.
units must match how the training dataset was recorded: degrees for anything after the lerobot 0.6.1 upgrade, normalized for older sets (their norm stats clamp at ±100). It cannot be inferred from the checkpoint — only the dataset name can.
RL policy · active
Trained in mjlab against one reward, so there is no task prompt and no chunking. Joints, home pose and action scale are read from the ONNX metadata — the only thing this page has to tell it is where the goal is.
Where the printed footprint sits in the robot base frame, measured not guessed. The camera does see the footprint, but the policy never learned to read it — ablated in sim over 32 episodes: true goal 96.9% solved to 2 mm, zeroed 0% at 103 mm, displaced 15 cm 0% at 89 mm. Wrong numbers do not degrade the push, they aim it somewhere else.
Where to lift the T to: a point in the air, x forward of the base and z above the table. No camera can see it, so state is the only place it can come from. Trained on x 0.10–0.22, |y| < 0.08, z 0.08–0.16 — outside that box the policy is extrapolating. The block itself it finds in the wrist image, so a wrong target misplaces the lift rather than breaking the grasp. This policy also drives the jaw at full scale, unlike Push-T's; run it dry first.
Trained at 50 Hz. The rate limit is a leash for a policy whose sim had a massless wrist — it can ask for a step change, and the real arm answering one at full torque is how a gripper meets a table.
The honest first run for a checkpoint that has only ever driven a simulated arm: watch the targets in the log before letting it drive.
Execution · any mode
